# Abstract

> แปลโดย thesis-editor จาก `00-บทคัดย่อ.md` (ฉบับวันที่ 3 พ.ย. 2569) ถ้าแก้ฉบับไทย ต้องแก้ฉบับนี้ให้ตรงกัน — ชื่อภาษาอังกฤษของ "กลุ่มงานตรวจชีววิทยาและดีเอ็นเอ" ยังไม่ได้ยืนยันกับหน่วยงาน

The Biology and DNA Examination Subdivision of Police Forensic Science Center 3 tracks DNA forensic case submissions in Excel and Google Sheets, with searching and summarizing performed manually. As a result, answering case status inquiries and preparing monthly summaries are time-consuming and prone to error. This project aims to develop a web-based dashboard and a LINE chatbot for monitoring and summarizing case submissions while protecting personal data in accordance with the Personal Data Protection Act B.E. 2562 (2019). The system is built on Google Apps Script and reads data from Google Sheets on the server side. Access to the dashboard is restricted by an email allowlist combined with view-only sharing of the spreadsheet. The chatbot, connected through the LINE Messaging API, reports case status by case number and summarizes pending cases in two separate groups. It uses the Gemini API for intent classification only on question text from which case numbers and personally identifiable information have already been removed, so that no case data are sent outside the system. Monthly and annual summaries are sent to the group automatically using the same set of calculation functions as the chatbot. The system was tested with 731 rows of mock data and mock Google, LINE, and Gemini services, and the results were compared with values computed independently in Python. All 114 test cases passed. The figures from the dashboard, the chatbot, and the summary reports matched for every value tested, access control rejected every case in which the conditions were not fully met, and the content sent to Gemini contained no data from the spreadsheet. It can be concluded that the system works as designed at the level of mock data; however, testing with real accounts and a real LINE group, together with a user satisfaction evaluation, is still required before full deployment.

Keywords: forensic DNA analysis, dashboard, LINE chatbot, Google Apps Script, large language model, personal data protection
