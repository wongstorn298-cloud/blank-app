# บทคัดย่อ

> ร่างโดย thesis-writer — บทคัดย่อภาษาไทย (ภาษาอังกฤษ thesis-editor จะแปลจากฉบับนี้) ตัวเลขผลทดสอบมาจากบทที่ 4

กลุ่มงานตรวจชีววิทยาและดีเอ็นเอ ศูนย์พิสูจน์หลักฐาน 3 ติดตามคดีส่งตรวจพิสูจน์ DNA ด้วย Excel และ Google Sheets โดยค้นหาและสรุปด้วยมือ ทำให้การตอบสถานะคดีและการจัดทำสรุปรายเดือนใช้เวลาและมีโอกาสคลาดเคลื่อน โครงงานนี้มีวัตถุประสงค์เพื่อพัฒนา Dashboard บนเว็บและแชตบอต LINE สำหรับติดตามและสรุปคดีส่งตรวจ โดยคุ้มครองข้อมูลส่วนบุคคลตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ระบบพัฒนาบน Google Apps Script ซึ่งอ่านข้อมูลจาก Google Sheets ฝั่งเซิร์ฟเวอร์ Dashboard จำกัดการเข้าถึงด้วยรายชื่ออีเมลร่วมกับการแชร์ Sheet แบบผู้มีสิทธิ์อ่าน แชตบอตเชื่อมต่อผ่าน LINE Messaging API ตอบสถานะคดีจากเลขคดีและสรุปคดีค้างแยก 2 กลุ่ม ใช้ Gemini API แยกเจตนาจากข้อความคำถามที่ตัดเลขคดีและข้อมูลระบุตัวบุคคลออกแล้วเท่านั้น โดยไม่ส่งข้อมูลคดีออกนอกระบบ และส่งสรุปรายเดือนและรายปีเข้ากลุ่มอัตโนมัติด้วยฟังก์ชันคำนวณชุดเดียวกับที่แชตบอตใช้ ระบบทดสอบด้วยข้อมูลจำลอง 731 แถวและบริการจำลองของ Google, LINE และ Gemini โดยเทียบผลกับค่าที่คำนวณอิสระด้วย Python ผลการทดสอบผ่านทั้ง 114 กรณี ตัวเลขจาก Dashboard แชตบอต และรายงานสรุปตรงกันทุกค่าที่ทดสอบ การตรวจสิทธิ์ปฏิเสธทุกกรณีที่เงื่อนไขไม่ครบ และเนื้อหาที่ส่งไปยัง Gemini ไม่มีข้อมูลจาก Sheet สรุปได้ว่าระบบทำงานถูกต้องตามที่ออกแบบในระดับข้อมูลจำลอง โดยยังต้องทดสอบกับบัญชีและกลุ่ม LINE จริง และประเมินความพึงพอใจของผู้ใช้ก่อนนำไปใช้งานเต็มรูปแบบ

คำสำคัญ: การตรวจพิสูจน์ DNA, Dashboard, แชตบอต LINE, Google Apps Script, แบบจำลองภาษาขนาดใหญ่, การคุ้มครองข้อมูลส่วนบุคคล
