# tools

## `make_mock_data.py` — สร้างข้อมูลจำลอง

สร้างไฟล์ตัวอย่างที่ Dashboard ใช้ในโหมด "ตัวอย่าง"

- `dashboard/samples/cases.xlsx` — แท็บ `ข้อมูลคดี` (~730 คดี ม.ค. 2565 – ต.ค. 2569) และ `ผู้ใช้`
- `dashboard/samples/lab.xlsx` — แท็บ `ข้อมูลเคส`, `ข้อมูลงบ`, `ข้อมูล Lot`, `หมายเหตุ`

วิธีสร้างใหม่ (ต้องมี `openpyxl`):

```bash
python3 tools/make_mock_data.py
```

- ใช้ seed และวันอ้างอิงคงที่ (`AS_OF = 31 ต.ค. 2026`) รันกี่ครั้งก็ได้ไฟล์เดิมทุกไบต์
- ข้อมูลทั้งหมดเป็นของสมมติ (เจ้าหน้าที่ ก–จ, สภ.ตัวอย่าง1–15, หนังสือ `ตย.0000/…`, อีเมล `@example.com`) ไม่มี DNA profile
- ไม่มีคอลัมน์ `User ID (LINE)` (เจ้าของลบออกจากชีตจริงแล้ว) สคริปต์ยังเรียกตัวสุ่มเท่าเดิม ข้อมูลส่วนอื่นและ `lab.xlsx` จึงเหมือนเดิมทุกค่า
- แก้โครงสร้างคอลัมน์ให้ตรงกับ `docs/data-schema.md` และตัวอ่านใน `dashboard/index.html` เสมอ
- ห้ามนำข้อมูลจริงมาใส่ในสคริปต์หรือไฟล์ตัวอย่าง

## `make_templates.py` — สร้างแม่แบบ Google Sheet เปล่า

สร้างไฟล์ใน `templates/` (ไม่มีแถวข้อมูล) ให้เจ้าของนำเข้า Google Sheets เอง วิธีใช้ดู `templates/README.md`

- `แม่แบบ-ชีตคดี.xlsx` — `คำอธิบาย`, `ข้อมูลคดี`
- `แม่แบบ-ชีตงานตรวจ.xlsx` — `คำอธิบาย`, `ข้อมูลเคส`, `ข้อมูลงบ`, `ข้อมูล Lot`, `หมายเหตุ`
- `แม่แบบ-ชีต-Lot-พัสดุ.xlsx` — `คำอธิบาย`, `ข้อมูล Lot`, `หมายเหตุ`

```bash
python3 tools/make_templates.py            # เขียนลง templates/
python3 tools/make_templates.py /path/out  # เขียนลงโฟลเดอร์อื่น (ใช้ตอนทดสอบ)
```

- ชื่อแท็บ/หัวคอลัมน์ import จาก `make_mock_data.py` เพื่อให้ตรงกับข้อมูลจำลองและตัวอ่านใน Dashboard / `Stats.gs` (แท็บข้อมูลคดีตัดคอลัมน์ช่วยคำนวณที่ระบบไม่อ่านออก)
- มี dropdown (สถานะ, ประเภทคดี, หมวดงบ, ที่มาของวันที่ Lot), รูปแบบวันที่/ข้อความ, ตรึงแถวหัวคอลัมน์ และสูตรที่ใช้ได้ทั้ง Excel และ Google Sheets (ข้อสังเกตในชีตคดี, เดือน/ปีปฏิทินในข้อมูลเคส, รอบพัสดุ/ปีงบ/วันที่ประมาณการใน Lot)
- ไบต์คงที่ รันซ้ำได้ไฟล์เดิม · `.gitignore` กัน `*.xlsx` ไว้ ต้องเพิ่มข้อยกเว้น `!templates/*.xlsx` หรือ `git add -f templates/`
- ห้ามกรอกข้อมูลจริงลงไฟล์ใน `templates/` แล้ว commit
