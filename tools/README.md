# tools

## `make_mock_data.py` — สร้างข้อมูลจำลอง

สร้างไฟล์ตัวอย่างที่ Dashboard ใช้ในโหมด "ตัวอย่าง"

- `dashboard/samples/cases.xlsx` — แท็บ `ข้อมูลคดี` (~730 คดี ม.ค. 2565 – ต.ค. 2569) และ `ผู้ใช้`
- `dashboard/samples/lab.xlsx` — แท็บ `ข้อมูลเคส`, `ข้อมูลงบ`, `ข้อมูล Lot`, `หมายเหตุ`

วิธีสร้างใหม่ (ต้องมี `openpyxl`):

```bash
python3 tools/make_mock_data.py
```

- ใช้ seed และวันอ้างอิงคงที่ (`AS_OF = 31 ต.ค. 2026`) รันกี่ครั้งก็ได้ไฟล์เดิมทุกไบต์
- ข้อมูลทั้งหมดเป็นของสมมติ (เจ้าหน้าที่ ก–จ, สภ.ตัวอย่าง1–15, หนังสือ `ตย.0000/…`, LINE `U-mock-…`, อีเมล `@example.com`) ไม่มี DNA profile
- แก้โครงสร้างคอลัมน์ให้ตรงกับ `docs/data-schema.md` และตัวอ่านใน `dashboard/index.html` เสมอ
- ห้ามนำข้อมูลจริงมาใส่ในสคริปต์หรือไฟล์ตัวอย่าง
