# เช็กลิสต์ติดตั้งชุดทดสอบ (ประมาณ 15 นาที)

ทำบน **คอมพิวเตอร์** ด้วยเบราว์เซอร์ Chrome ล็อกอิน Gmail ที่จะเป็นเจ้าของชุดทดสอบไว้ก่อน
เปิดเช็กลิสต์นี้ไว้บนมือถือ แล้วทำตามบนคอมพิวเตอร์ทีละข้อ

## ก. ชีต (3 นาที)

- [ ] 1. ดาวน์โหลดชีตตั้งต้น: https://github.com/wongstorn298-cloud/blank-app/raw/ccr-14d76a3c-2khfwc/inventory-app/starter-sheet.xlsx
- [ ] 2. เปิด https://drive.google.com → **+ ใหม่** → **อัปโหลดไฟล์** → เลือก `starter-sheet.xlsx`
- [ ] 3. ดับเบิลคลิกไฟล์ → เมนู **ไฟล์** → **บันทึกเป็น Google ชีต**
- [ ] 4. ในไฟล์ใหม่ที่เปิดขึ้น เปลี่ยนชื่อมุมซ้ายบนเป็น `[ทดสอบ] คลังน้ำยา`

## ข. วางโค้ด (5 นาที)

- [ ] 5. ในชีต เมนู **ส่วนขยาย** → **Apps Script** (เปิดแท็บใหม่)
- [ ] 6. เปิดแท็บใหม่อีกแท็บไปที่ https://raw.githubusercontent.com/wongstorn298-cloud/blank-app/ccr-14d76a3c-2khfwc/inventory-app/Code.gs
      กด `Ctrl+A` แล้ว `Ctrl+C`
- [ ] 7. กลับไปแท็บ Apps Script คลิกในช่องโค้ด กด `Ctrl+A` แล้ว `Ctrl+V` (แทนที่ของเดิม) → `Ctrl+S`
- [ ] 8. ด้านซ้าย ข้างคำว่า **ไฟล์** กด **+** → **HTML** → พิมพ์ `index` (ตัวเล็ก ไม่ต้องมี .html) → Enter
- [ ] 9. เปิดแท็บใหม่ไปที่ https://raw.githubusercontent.com/wongstorn298-cloud/blank-app/ccr-14d76a3c-2khfwc/inventory-app/index.html
      กด `Ctrl+A` แล้ว `Ctrl+C`
- [ ] 10. กลับไปที่ไฟล์ `index.html` ใน Apps Script คลิกในช่องโค้ด `Ctrl+A` แล้ว `Ctrl+V` → `Ctrl+S`

## ค. อนุญาตสิทธิ์ (2 นาที)

- [ ] 11. คลิกไฟล์ `รหัส.gs` (หรือ `Code.gs`) → ช่องเลือกฟังก์ชันด้านบน เลือก `setup` → กด **▷ เรียกใช้**
- [ ] 12. **ตรวจสอบสิทธิ์** → เลือกบัญชี → **ขั้นสูง** → **ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต**
      (คำเตือนนี้ปกติสำหรับสคริปต์ที่เขียนเอง)
- [ ] 13. ด้านล่างต้องขึ้น `พร้อมใช้งาน: Equipment_Master 30 แถว, …`

## ง. ได้ลิงก์ (3 นาที)

- [ ] 14. มุมขวาบน **ทำให้ใช้งานได้** → **การทำให้ใช้งานได้รายการใหม่** → ไอคอนเฟือง ⚙ → **เว็บแอป**
- [ ] 15. ตั้งค่า
      **คำอธิบาย:** `ทดสอบ`
      **ดำเนินการในฐานะ:** **ฉัน**
      **ผู้ที่มีสิทธิ์เข้าถึง:** **ทุกคน** (ไม่ใช่ "ทุกคนที่มีบัญชี Google")
      → **ทำให้ใช้งานได้** (ถ้าขอสิทธิ์อีก อนุญาตแบบข้อ 12)
- [ ] 16. กด **คัดลอก** URL ที่ลงท้ายด้วย `/exec` นี่คือลิงก์ทดสอบ
- [ ] 17. วางลิงก์ในเบราว์เซอร์ ต้องเห็นแอปที่มีตราศูนย์ฯ ปุ่มมุมขวาบนขึ้น **ซิงก์แล้ว**
- [ ] 18. ส่งลิงก์ในกลุ่ม LINE ให้เจ้าหน้าที่ทดสอบ

---

**ติดขัดตรงไหน** แคปหน้าจอส่งมาพร้อมบอกเลขข้อ

| อาการ | แก้ |
| --- | --- |
| ข้อ 11 หาฟังก์ชัน `setup` ไม่เจอ | ข้อ 7 วางไม่ครบหรือยังไม่ได้บันทึก (`Ctrl+S`) |
| ข้อ 13 ขึ้น "หัวตารางของชีต … ไม่ตรง" | ข้อ 3 ไม่ได้บันทึกเป็น Google ชีต หรือหัวตารางถูกแก้ |
| ข้อ 17 ขึ้นให้ลงชื่อเข้า Google | ข้อ 15 เลือกสิทธิ์ผิด: **จัดการการทำให้ใช้งานได้** → ✎ → ผู้ที่มีสิทธิ์เข้าถึง **ทุกคน** → **เวอร์ชันใหม่** |
| ข้อ 17 หน้าว่างหรือ error เรื่องไฟล์ `index` | ข้อ 8 ตั้งชื่อไฟล์ผิด หรือข้อ 10 วางไม่ครบ แก้แล้วทำ **เวอร์ชันใหม่** ตามด้านบน |
