# คลังน้ำยาแล็บ DNA (v2)

เว็บแอปคลังวัสดุและบำรุงรักษาเครื่องมือ ออกแบบให้ใช้บนมือถือเป็นหลัก เก็บข้อมูลใน Google Sheets 3 ชีต และส่งออกรายงาน Excel (.xlsx) ได้

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บทั้งหมด (Tailwind CSS, Chart.js, SheetJS) เปิดได้ทันที มีข้อมูลตัวอย่างย้อนหลังประมาณ 3 ปี |
| `Code.gs` | Google Apps Script ฝั่งเซิร์ฟเวอร์ |
| `dev/gas-fake-server.js` | รัน `Code.gs` บนเครื่องด้วย Node (Sheets จำลองในหน่วยความจำ) ไว้ทดสอบโดยไม่ต้องใช้ Google |

## โครงสร้างข้อมูล

| ชีต | เก็บอะไร | การแก้ไข |
| --- | --- | --- |
| `Equipment_Master` | ทะเบียนอุปกรณ์/วัสดุ 1 แถวต่อ 1 รายการ: `Equipment_ID` (EQ-001…), `Material_Name`, `Category` (สิ้นเปลือง / ทรัพย์สินถาวร), `Unit`, `Min_Stock_Alert`, `Expiration_Date`, `Next_Maintenance_Date`, `Updated_At` | แก้ไขได้ (เช่น เปลี่ยนวันหมดอายุเมื่อรับล็อตใหม่ หรือเลื่อนวันบำรุงรักษาหลังทำ PM) |
| `Transactions` | การรับ-เบิกทุกครั้ง: `Transaction_ID`, `Timestamp`, `Equipment_ID`, `Type` (IN/OUT), `Quantity`, `Requester`, `Notes` | **เพิ่มแถวอย่างเดียว** ไม่แก้ ไม่ลบ บันทึกผิดให้บันทึกรายการกลับทิศ |
| `Maintenance_Log` | ใบแจ้งซ่อม: `Repair_ID`, `Timestamp`, `Equipment_ID`, `Issue_Description`, `Reporter`, `Status`, `Updated_At` | แก้ได้เฉพาะ `Status` |

ไม่มีการเก็บยอดคงเหลือไว้ที่ใดเลย ทุกตัวเลขคำนวณใหม่จาก `Transactions` ทุกครั้ง

- **ยอดยกมา** = ผลรวม IN − OUT ของรายการก่อนวันเริ่มต้น
- **รับเข้าในช่วง / เบิกออกในช่วง** = ผลรวม IN / OUT ระหว่างวันเริ่มต้นถึงวันสิ้นสุด
- **คงเหลือ** = ยอดยกมา + รับเข้า − เบิกออก (ยอด ณ วันสิ้นสุด)

ข้อมูลเก่าจึงไม่ต้องลบ ยอดยกมาของช่วงไหนก็คำนวณได้ถูกต้องเสมอ กดรายการในหน้า **คงคลัง** จะเห็น "บัญชีคุมยอด" ที่ไล่ยอดทีละรายการตั้งแต่ยอดยกมาจนถึงคงเหลือ

**การแจ้งเตือน** ดูจากทะเบียนอย่างเดียว ไม่ขึ้นกับช่วงวันที่ที่เลือก:
- `Expiration_Date` เหลือไม่เกิน 30 วันหรือเลยแล้ว
- `Next_Maintenance_Date` เหลือไม่เกิน 30 วันหรือเลยแล้ว
- คงเหลือปัจจุบัน ≤ `Min_Stock_Alert` (แสดงแยก ไม่นับในตัวเลข "แจ้งเตือนเร่งด่วน")

## เชื่อมต่อ Google Sheets

### 1. วางโค้ด
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก `Code.gs`
3. แก้ `const API_KEY = '';` ใส่รหัสลับที่คาดเดายาก
4. กด **บันทึก**

### 2. สร้างชีต
เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์ (บัญชี → ขั้นสูง → ไปที่โปรเจกต์ → อนุญาต) จะได้ 3 แท็บ `Equipment_Master`, `Transactions`, `Maintenance_Log` พร้อมหัวตาราง

### 3. Deploy
**ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
- ดำเนินการในฐานะ: **ฉัน**
- ผู้มีสิทธิ์เข้าถึง: **ทุกคน**

คัดลอก URL ที่ลงท้ายด้วย `/exec`

### 4. ใส่ในแอป
แท็บ **ตั้งค่า** → วาง URL และรหัสลับ → **ทดสอบการเชื่อมต่อ** → **บันทึกและซิงก์**
ข้อมูลตัวอย่างจะถูกแทนด้วยข้อมูลในชีต (ไม่ถูกส่งเข้าชีต) จากนั้นเริ่มจากเพิ่มรายการในแท็บ **ทะเบียน** แล้วบันทึกรับเข้ายอดตั้งต้น

แก้ `Code.gs` ภายหลังต้อง Deploy เวอร์ชันใหม่: **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL เดิมใช้ต่อได้

## การซิงก์

- **รหัส EQ ออกโดยเซิร์ฟเวอร์** เพื่อไม่ให้มือถือสองเครื่องได้รหัสซ้ำ ถ้าชื่อซ้ำกับรายการเดิม จะใช้รหัสเดิม
- **ดึงเฉพาะแถวใหม่:** เพราะ `Transactions` เพิ่มแถวอย่างเดียว แอปจำว่ามีแล้วกี่แถว และขอเฉพาะแถวที่ต่อจากนั้น ถ้ามีคนลบแถวในชีตเอง แอปจะดาวน์โหลดใหม่ทั้งหมดอัตโนมัติ
- **ออฟไลน์ได้:** ถ้าเน็ตหลุด รายการจะเก็บไว้ในเครื่อง ปุ่มมุมขวาบนขึ้น "รอส่ง" อุปกรณ์ที่เพิ่มตอนออฟไลน์จะได้รหัสชั่วคราว `TMP-…` และเปลี่ยนเป็น EQ จริงตอนส่ง พร้อมแก้รหัสในรายการรับ-เบิกที่อ้างถึงให้
- **กันข้อมูลผิด:** เซิร์ฟเวอร์ตรวจรหัสอุปกรณ์ จำนวน วันที่ และไม่ยอมให้เบิกเกินยอดคงเหลือ ส่งซ้ำ (เช่น กดซ้ำตอนเน็ตช้า) จะไม่เกิดแถวซ้ำ
- `GET ?action=report&start=YYYY-MM-DD&end=YYYY-MM-DD&key=…` ให้เซิร์ฟเวอร์คำนวณยอดยกมา/รับ/เบิก/คงเหลือ คืนเป็น JSON ใช้กับเครื่องมืออื่นได้

## ขีดจำกัดที่ควรรู้

Google Sheets รับได้สูงสุด 10 ล้านเซลล์ต่อไฟล์ ชีต `Transactions` ใช้ 7 คอลัมน์ จึงเก็บได้ราว 1.4 ล้านแถว ถ้าบันทึกวันละ 100 รายการ จะใช้ได้ประมาณ 38 ปี ส่วนตัวแอปบนมือถือคำนวณหลักหมื่นถึงแสนแถวได้ทันที

## Excel

- **รายงานตามช่วง:** หน้า **ภาพรวม** → เลือกช่วงวันที่ (และอุปกรณ์ถ้าต้องการ) → **Export Report to Excel (.xlsx)** ได้ 4 แท็บ: สรุปคงคลัง, รายการรับ-เบิก, แจ้งซ่อม, ทะเบียนอุปกรณ์
- **ข้อมูลดิบทั้งหมด:** Google Sheet → **ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)**

## ใช้งานบนมือถือ

นำ `index.html` ขึ้นเว็บ (เช่น GitHub Pages หรือลากโฟลเดอร์ไปที่ app.netlify.com/drop) เปิดในมือถือแล้วเลือก **เพิ่มไปยังหน้าจอหลัก** แต่ละเครื่องต้องตั้งค่า URL และรหัสลับเอง

## ทดสอบบนเครื่อง

```bash
node inventory-app/dev/gas-fake-server.js inventory-app/Code.gs 8787 test-key
```

แล้วในแอปใส่ URL `http://localhost:8787/exec` และรหัส `test-key` (แอปยอมรับ `localhost` ไว้สำหรับทดสอบ)

## ความปลอดภัย

ใครมี Web App URL และรหัสลับ จะเขียนข้อมูลเข้าชีตได้ ตั้ง `API_KEY` เสมอ และไม่เผยแพร่ทั้งสองอย่าง ถ้าหลุดให้เปลี่ยนรหัสและ Deploy ใหม่
