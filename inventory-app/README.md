# คลังน้ำยาแล็บ DNA

เว็บแอปบันทึกสต็อกน้ำยา วัสดุสิ้นเปลือง และงานบำรุงรักษาเครื่องมือ ออกแบบให้ใช้บนมือถือเป็นหลัก ส่งข้อมูลเข้า Google Sheets ทันทีที่บันทึก และส่งออกรายงานเป็น Excel (.xlsx) ได้

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บทั้งหมด (Tailwind CSS, Chart.js, SheetJS) เปิดได้ทันที มีข้อมูลตัวอย่างโหลดไว้แล้ว |
| `Code.gs` | โค้ดฝั่ง Google Apps Script รับข้อมูลจากแอปแล้วเพิ่มแถวลง Google Sheet |

## ลองใช้ทันที (ไม่ต้องเชื่อมต่อ)

เปิด `index.html` ด้วยเบราว์เซอร์ แอปจะโหลดข้อมูลสมมติย้อนหลังประมาณ 14 เดือน (รายการวัสดุจริงของแล็บ) ใช้ทดลองตัวกรองวันที่ การคำนวณยอด และการแจ้งเตือนได้เลย ข้อมูลที่บันทึกในโหมดนี้เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น

## เชื่อมต่อ Google Sheets

### 1. สร้างชีตและวางโค้ด

1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `คลังน้ำยาแล็บ DNA`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ `Code.gs` นี้
4. (แนะนำ) แก้บรรทัด `const API_KEY = '';` ใส่รหัสลับที่คาดเดายาก เช่น `const API_KEY = 'lab-3500-x9Kp2';`
5. กด **บันทึก** (ไอคอนแผ่นดิสก์)

### 2. สร้างชีตอัตโนมัติ

1. เลือกฟังก์ชัน `setup` จากเมนูด้านบน แล้วกด **เรียกใช้**
2. Google จะขออนุญาต: เลือกบัญชี → **ขั้นสูง** → **ไปที่ (ชื่อโปรเจกต์)** → **อนุญาต**
3. กลับไปที่ชีต จะเห็นแท็บใหม่ `รายการสต็อก` และ `แจ้งซ่อม` พร้อมหัวตาราง

### 3. Deploy เป็น Web App

1. ใน Apps Script กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
2. คลิกไอคอนเฟือง เลือกประเภท **เว็บแอป**
3. ตั้งค่า
   - **ดำเนินการในฐานะ:** ฉัน
   - **ผู้มีสิทธิ์เข้าถึง:** ทุกคน
4. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

### 4. ใส่ URL ในแอป

1. เปิดแอป ไปที่แท็บ **ตั้งค่า**
2. วาง Web App URL และรหัสลับ (ถ้าตั้งไว้)
3. กด **ทดสอบการเชื่อมต่อ** ต้องขึ้นข้อความ "เชื่อมต่อได้"
4. กด **บันทึกและซิงก์** ข้อมูลในแอปจะเปลี่ยนเป็นข้อมูลจากชีต (ข้อมูลตัวอย่างจะไม่ถูกส่งเข้าชีต)

หลังจากนี้ทุกครั้งที่กดบันทึกในมือถือ จะเพิ่มแถวใหม่ในชีตทันที ถ้าอินเทอร์เน็ตหลุด รายการจะเก็บไว้ในเครื่องและแสดงสถานะ "รอส่ง" ที่มุมขวาบน กดปุ่มนั้นแล้วเลือก **ส่งรายการค้างและดึงข้อมูลล่าสุด** เพื่อส่งใหม่

### แก้โค้ด Code.gs ภายหลัง

ต้อง Deploy ใหม่ทุกครั้งที่แก้โค้ด: **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ไอคอนดินสอ) → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** URL เดิมยังใช้ได้

## ใช้งานบนมือถือ

ต้องนำ `index.html` ขึ้นเว็บก่อน เพื่อให้เปิดจากมือถือได้ วิธีที่ง่ายที่สุดคือ

- **GitHub Pages:** ตั้งค่า repo → Pages → เลือก branch แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/<repo>/inventory-app/`
- **Netlify Drop:** ลากโฟลเดอร์ `inventory-app` ไปวางที่ app.netlify.com/drop

เปิดลิงก์ในมือถือ แล้วเลือก **เพิ่มไปยังหน้าจอหลัก** จะใช้งานได้เหมือนแอป

ค่า URL และรหัสลับเก็บไว้ในเบราว์เซอร์ของแต่ละเครื่อง ทุกเครื่องที่ใช้งานต้องตั้งค่าครั้งแรกเอง

## ดาวน์โหลดเป็น Excel

- **รายงานตามช่วงวันที่:** หน้า **ภาพรวม** เลือกช่วงวันที่และวัสดุ แล้วกด **ส่งออก Excel (.xlsx)** ไฟล์มี 4 แท็บ: สรุป, คงคลัง, รายการเคลื่อนไหว, แจ้งซ่อม
- **ข้อมูลดิบทั้งหมด:** เปิด Google Sheet → **ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)**

## วิธีคำนวณ

- **ยอดยกมา** = รับเข้ารวม − เบิกออกรวม ของทุกรายการก่อนวันเริ่มต้น
- **รับเข้า / เบิกออกทั้งหมด** = ผลรวมจำนวนในช่วงที่เลือก
- **คงเหลือปัจจุบัน** = ยอดยกมา + รับเข้า − เบิกออก (ยอด ณ วันสิ้นสุดของช่วง)
- เมื่อเลือก "วัสดุทั้งหมด" ตัวเลขเป็นผลรวมของทุกหน่วยนับ (ชุด ขวด แพ็ก ฯลฯ) เลือกวัสดุรายตัวเพื่อดูยอดที่หน่วยตรงกัน
- **วันหมดอายุ** แสดงล็อตที่หมดอายุเร็วที่สุดที่ยังมีของเหลือ โดยตัดสต็อกแบบหมดอายุก่อนจ่ายก่อน (FEFO) ล็อตที่หมดอายุแล้วจะไม่ถูกตัดก่อน
- **แจ้งเตือนเร่งด่วน** = จำนวนวัสดุที่หมดอายุแล้วหรือจะหมดอายุภายใน 30 วัน (และยังมีของเหลือ) รวมกับอุปกรณ์ที่ถึงกำหนดบำรุงรักษาภายใน 30 วันหรือเลยกำหนด
- สีวันหมดอายุ: แดง = หมดอายุแล้ว หรือเหลือไม่เกิน 30 วัน, เหลือง = เหลือไม่เกิน 90 วัน
- บันทึกวันบำรุงรักษาอย่างเดียวโดยไม่เปลี่ยนยอด: ใส่จำนวน `0` แล้วกรอกวันครบกำหนดบำรุงรักษา

## ความปลอดภัย

Web App ที่ตั้ง "ทุกคน" เข้าถึงได้ หมายความว่าใครมี URL ก็ส่งข้อมูลเข้าชีตได้ จึงควรตั้ง `API_KEY` และไม่เผยแพร่ URL หรือรหัสลับในที่สาธารณะ ถ้า URL หลุด ให้สร้าง Deploy ใหม่และเปลี่ยนรหัสลับ
