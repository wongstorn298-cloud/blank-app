# คู่มือติดตั้งและใช้งาน
## ระบบคลังน้ำยาและบำรุงรักษาเครื่องมือ
กลุ่มงานตรวจชีววิทยาและดีเอ็นเอ ศูนย์พิสูจน์หลักฐาน 3

คู่มือนี้มี 4 ส่วน

1. [ติดตั้งระบบ](#ส่วนที่-1-ติดตั้งระบบ) สำหรับผู้ดูแลระบบ ทำครั้งเดียวบนคอมพิวเตอร์ ประมาณ 20–30 นาที
2. [ใช้งานบนมือถือ](#ส่วนที่-2-ใช้งานบนมือถือ) สำหรับเจ้าหน้าที่ทุกคน
3. [งานของผู้ดูแลระบบ](#ส่วนที่-3-งานของผู้ดูแลระบบ) สำรองข้อมูล อัปเดตโปรแกรม เปลี่ยนลิงก์
4. [แก้ปัญหาที่พบบ่อย](#ส่วนที่-4-แก้ปัญหาที่พบบ่อย)

---

## ภาพรวมของระบบ

```
มือถือเจ้าหน้าที่  ──เปิดลิงก์──▶  Google Apps Script (ตัวแอป)  ──อ่าน/เขียน──▶  Google Sheet
                                                                              ├─ Equipment_Master  ทะเบียนอุปกรณ์
                                                                              ├─ Transactions      บันทึกรับ-เบิก
                                                                              └─ Maintenance_Log   ใบแจ้งซ่อม
```

- ข้อมูลทั้งหมดอยู่ใน Google Sheet ไฟล์เดียว ในบัญชี Google ของกลุ่มงาน
- เจ้าหน้าที่ใช้ลิงก์เดียวกัน เปิดในมือถือได้เลย ไม่ต้องติดตั้งแอปจาก App Store หรือ Play Store และไม่ต้องลงชื่อเข้าใช้
- ยอดคงเหลือไม่ได้เก็บไว้ในชีต แอปคำนวณใหม่จากบันทึกรับ-เบิกทุกครั้ง จึงไม่ต้องลบข้อมูลเก่า

## ส่วนที่ 1 ติดตั้งระบบ

> ทำบนคอมพิวเตอร์ ด้วยบัญชี Gmail ที่จะเป็นเจ้าของข้อมูล (แนะนำให้ใช้บัญชีกลางของกลุ่มงาน ไม่ใช่บัญชีส่วนตัวของคนใดคนหนึ่ง เพื่อไม่ให้ข้อมูลหายเมื่อคนนั้นย้ายงาน)
>
> เมนูของ Google ในคู่มือนี้เขียนเป็นภาษาไทย ถ้าหน้าจอของคุณเป็นภาษาอังกฤษ ให้ดูชื่อในวงเล็บ

### 1.1 ดาวน์โหลดไฟล์ 3 ไฟล์

ไฟล์อยู่ในโฟลเดอร์ `inventory-app` ของ repository นี้

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `starter-sheet.xlsx` | ชีตตั้งต้น มีทะเบียนอุปกรณ์ 30 รายการ ยอดเป็น 0 |
| `Code.gs` | โค้ดฝั่ง Google Apps Script |
| `index.html` | ตัวแอป (มีตราศูนย์ฯ ฝังอยู่ในไฟล์แล้ว) |

วิธีดาวน์โหลดจาก GitHub: กดชื่อไฟล์ แล้วกดปุ่ม **Download raw file** (ไอคอนลูกศรลง) ที่มุมขวาบนของกรอบไฟล์

### 1.2 ตรวจข้อมูลตั้งต้น (แนะนำให้ทำก่อน)

เปิด `starter-sheet.xlsx` ด้วย Excel หรือข้ามไปแก้ใน Google Sheet ในขั้นตอนถัดไปก็ได้

แท็บ **Equipment_Master** มี 30 รายการจากรายชื่อพัสดุที่ส่งมา (ตัดชื่อซ้ำออกแล้ว) ให้ตรวจ:

| คอลัมน์ | ต้องทำ |
| --- | --- |
| `Unit` หน่วยนับ | **ผู้พัฒนาเดาไว้** (ชุด ขวด แพ็ก หลอด กล่อง ชิ้น เครื่อง) ให้แก้ให้ตรงกับหน่วยที่ใช้เบิกจริง |
| `Min_Stock_Alert` จุดเตือนสต็อก | ตั้งไว้ 0 ทุกรายการ (ยังไม่เตือน) ใส่ตัวเลขที่ต้องการให้เตือนเมื่อของเหลือเท่านี้หรือน้อยกว่า |
| `Expiration_Date` วันหมดอายุ | ว่างไว้ ใส่ได้ในรูปแบบ `2027-03-31` (ปี ค.ศ.-เดือน-วัน) |
| `Next_Maintenance_Date` วันบำรุงรักษาครั้งถัดไป | ว่างไว้ ใส่สำหรับเครื่องมือ (EQ-028 ถึง EQ-030) |
| `Category` ประเภท | สิ้นเปลือง หรือ ทรัพย์สินถาวร |

- รายการ "ค่าเบ็ดเตล็ด (เสื้อ + ปักโลโก้ + ปักชื่อ)" อยู่ในรายชื่อพัสดุเดิม ถ้าไม่ต้องการติดตามในคลัง ลบทั้งแถวได้ **เฉพาะตอนนี้** (ก่อนเริ่มใช้งาน)
- ห้ามแก้แถวที่ 1 (หัวตาราง) และห้ามเปลี่ยนชื่อแท็บ
- ถ้าลบแถว รหัส EQ จะข้ามเลขได้ ไม่เป็นปัญหา

### 1.3 นำชีตเข้า Google Drive

1. เปิด [drive.google.com](https://drive.google.com) ด้วยบัญชีของกลุ่มงาน
2. กด **+ ใหม่ (New)** → **อัปโหลดไฟล์ (File upload)** → เลือก `starter-sheet.xlsx`
3. ดับเบิลคลิกไฟล์ที่อัปโหลด จะเปิดในโหมด Excel (มีป้าย `.XLSX` ข้างชื่อ)
4. เมนู **ไฟล์ (File)** → **บันทึกเป็น Google ชีต (Save as Google Sheets)**
5. ไฟล์ใหม่จะเปิดขึ้นมา (ไม่มีป้าย `.XLSX` แล้ว) เปลี่ยนชื่อไฟล์ที่มุมซ้ายบนเป็น `คลังน้ำยา ศพฐ.3`
6. ตรวจว่ามี 4 แท็บด้านล่าง: `Equipment_Master`, `Transactions`, `Maintenance_Log`, `อ่านก่อน`
7. ลบไฟล์ `starter-sheet.xlsx` ตัวเดิมใน Drive ทิ้งได้ เพื่อไม่ให้สับสน

> ต่อจากนี้ทำงานในไฟล์ Google ชีตตัวใหม่เท่านั้น

### 1.4 เปิด Apps Script

1. ในไฟล์ Google ชีต เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
2. แท็บใหม่จะเปิดขึ้น กดชื่อ **โปรเจ็กต์ที่ไม่มีชื่อ (Untitled project)** มุมซ้ายบน แล้วเปลี่ยนเป็น `คลังน้ำยา ศพฐ.3` → **เปลี่ยนชื่อ**

### 1.5 ใส่ไฟล์ Code.gs

1. ด้านซ้ายจะมีไฟล์ชื่อ `รหัส.gs` (หรือ `Code.gs`) เปิดอยู่
2. คลิกในช่องโค้ด กด `Ctrl+A` (Mac: `⌘+A`) แล้วกด `Delete` ให้ว่าง
3. เปิดไฟล์ `Code.gs` ที่ดาวน์โหลดมาด้วย Notepad (Mac: TextEdit) คัดลอกทั้งหมด แล้ววางลงในช่องโค้ด
4. กด `Ctrl+S` หรือไอคอนแผ่นดิสก์ เพื่อบันทึก

### 1.6 ใส่ไฟล์ index.html

1. ด้านซ้าย ตรงคำว่า **ไฟล์ (Files)** กดเครื่องหมาย **+** → **HTML**
2. พิมพ์ชื่อ `index` **ตัวพิมพ์เล็กทั้งหมด ไม่ต้องพิมพ์ .html** แล้วกด Enter
3. ลบโค้ดตัวอย่างในไฟล์ใหม่ทั้งหมด (`Ctrl+A` แล้ว `Delete`)
4. เปิด `index.html` ที่ดาวน์โหลดมาด้วย Notepad คัดลอกทั้งหมด (ไฟล์ยาวประมาณ 1,500 บรรทัด ต้องได้ครบ) แล้ววาง
5. กด `Ctrl+S` เพื่อบันทึก

ตอนนี้ด้านซ้ายต้องมี 2 ไฟล์: `รหัส.gs` (หรือ `Code.gs`) และ `index.html`

### 1.7 รัน setup และอนุญาตสิทธิ์

1. กลับไปที่ไฟล์ `รหัส.gs`
2. แถบด้านบน ช่องเลือกฟังก์ชัน (ข้างปุ่ม **แก้ไขข้อบกพร่อง/Debug**) เลือก `setup`
3. กด **▷ เรียกใช้ (Run)**
4. จะขึ้นหน้าต่าง **ต้องมีการให้สิทธิ์ (Authorization required)** → กด **ตรวจสอบสิทธิ์ (Review permissions)**
5. เลือกบัญชีของกลุ่มงาน
6. จะขึ้นคำเตือน **Google ยังไม่ได้ยืนยันแอปนี้ (Google hasn't verified this app)** ซึ่งเป็นเรื่องปกติของสคริปต์ที่เขียนเอง
   กด **ขั้นสูง (Advanced)** → **ไปที่ คลังน้ำยา ศพฐ.3 (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
7. ด้านล่างจะขึ้น **บันทึกการดำเนินการ (Execution log)** ต้องเห็นข้อความ
   `พร้อมใช้งาน: Equipment_Master 30 แถว, Transactions 0 แถว, Maintenance_Log 0 แถว`

ถ้าขึ้นข้อความ `หัวตารางของชีต ... ไม่ตรง` แปลว่าแถวที่ 1 ของแท็บนั้นถูกแก้ ให้แก้กลับตามที่ข้อความบอก แล้วรัน `setup` ใหม่

### 1.8 เผยแพร่เป็นเว็บแอป (Deploy)

1. มุมขวาบน กด **ทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดไอคอนเฟือง ⚙ ข้างคำว่า **เลือกประเภท (Select type)** → เลือก **เว็บแอป (Web app)**
3. กรอก
   - **คำอธิบาย (Description):** `ใช้งานจริง`
   - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me)** ← สำคัญ
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** ← สำคัญ ห้ามเลือก "ทุกคนที่มีบัญชี Google"
4. กด **ทำให้ใช้งานได้ (Deploy)** (ถ้าขอสิทธิ์อีกรอบ ให้อนุญาตแบบเดียวกับข้อ 1.7)
5. จะได้ **URL ของเว็บแอป** ลงท้ายด้วย `/exec` กด **คัดลอก (Copy)** แล้วเก็บไว้

> ลิงก์นี้คือ "ตัวแอป" ที่เจ้าหน้าที่จะใช้ ใครมีลิงก์นี้จะเปิดและบันทึกข้อมูลได้ ส่งให้เฉพาะในกลุ่มงาน

### 1.9 ทดสอบ

1. วางลิงก์ในเบราว์เซอร์บนคอมพิวเตอร์
2. ต้องเห็นแอปที่มีแถบเมนูสีแดงเลือดหมูด้านซ้าย พร้อมตราศูนย์ฯ
3. ปุ่มมุมขวาบนต้องขึ้น **ซิงก์แล้ว** (สีเขียว)
4. กดเมนู **ทะเบียนอุปกรณ์** ต้องเห็น 30 รายการ (EQ-001 ถึง EQ-030)
5. ลองเปิดลิงก์เดียวกันบนมือถือของตัวเอง

### 1.10 ลงยอดตั้งต้น (ตรวจนับครั้งแรก)

ระบบเริ่มที่ยอด 0 ทุกรายการ ให้ตรวจนับของในคลังแล้วบันทึกเป็น "รับเข้า" หนึ่งครั้งต่อรายการ

1. ไปที่เมนู **บันทึก** → **รับ-เบิก**
2. เลือกอุปกรณ์ → กด **+ รับเข้า** → ใส่จำนวนที่นับได้
3. **วันที่ทำรายการ**: ใส่วันที่ตรวจนับ
4. **หมายเหตุ**: `ยอดยกมาจากการตรวจนับ` (จะได้แยกออกจากการรับของจริง)
5. กด **บันทึกรายการ** ทำซ้ำจนครบทุกรายการที่มีของ

ระหว่างนี้ให้ตั้งจุดเตือนสต็อก วันหมดอายุ และวันบำรุงรักษาในเมนู **ทะเบียนอุปกรณ์** → **แก้ไข** ได้เลย (ถ้ายังไม่ได้ทำในข้อ 1.2)

### 1.11 ส่งลิงก์ให้เจ้าหน้าที่

- ส่งลิงก์ในกลุ่ม LINE ของกลุ่มงาน
- หรือทำ QR code: เปิดลิงก์ใน Chrome บนคอมพิวเตอร์ → กดไอคอนแชร์ในช่องที่อยู่ → **สร้างคิวอาร์โค้ด (Create QR code)** → ดาวน์โหลดแล้วพิมพ์ติดไว้ที่ห้องเก็บน้ำยา
- ให้เจ้าหน้าที่ทำตามส่วนที่ 2.1 เพื่อเพิ่มไอคอนไว้ที่หน้าจอโฮม

## ส่วนที่ 2 ใช้งานบนมือถือ

### 2.1 เปิดครั้งแรก และเพิ่มไอคอนไว้ที่หน้าจอโฮม

> ถ้ากดลิงก์จากใน LINE แล้วแอปเปิดในหน้าต่างของ LINE ให้กดเมนู ⋯ มุมขวาบน → **เปิดในเบราว์เซอร์** ก่อน เพื่อให้เพิ่มไว้ที่หน้าจอโฮมได้

**iPhone / iPad (ต้องใช้ Safari)**
1. เปิดลิงก์ใน Safari
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น) ที่แถบด้านล่าง
3. เลื่อนลง กด **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
4. ตั้งชื่อสั้น ๆ เช่น `คลังน้ำยา` → กด **เพิ่ม**

**Android (Chrome)**
1. เปิดลิงก์ใน Chrome
2. กดปุ่ม **⋮** มุมขวาบน
3. กด **เพิ่มลงในหน้าจอหลัก (Add to Home screen)** → **เพิ่ม**

ต่อไปกดไอคอนนั้นเพื่อเข้าแอปได้เลย

สิ่งที่เป็นเรื่องปกติ ไม่ต้องตกใจ:
- ด้านบนสุดอาจมีแถบข้อความของ Google ว่า *"แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script"* เพราะแอปทำงานบนระบบของ Google
- ไอคอนบนหน้าจอโฮมอาจเป็นภาพย่อของหน้าจอ แทนที่จะเป็นตราศูนย์ฯ (ข้อจำกัดของ Google Apps Script)
- เปิดครั้งแรกจะขึ้นข้อความ "กำลังโหลดข้อมูลจาก Google Sheets…" รอ 2–5 วินาที

### 2.2 รู้จักหน้าจอ

**เมนูด้านล่าง 5 ปุ่ม**

| ปุ่ม | ใช้ทำอะไร |
| --- | --- |
| **ภาพรวม** | ตัวเลขสรุปตามช่วงวันที่ รายการที่ต้องดำเนินการ กราฟ รายการล่าสุด ปุ่มส่งออก Excel |
| **บันทึก** | ฟอร์มรับเข้า/เบิกออก และฟอร์มแจ้งซ่อม |
| **คงคลัง** | ยอดของทุกรายการ ค้นหา กรอง และดูบัญชีคุมยอด |
| **ทะเบียน** | เพิ่มอุปกรณ์ใหม่ แก้หน่วย จุดเตือน วันหมดอายุ วันบำรุงรักษา |
| **ตั้งค่า** | สถานะการเชื่อมต่อ ปุ่มซิงก์ เลือกโหมดสว่าง/มืด |

**ปุ่มสถานะมุมขวาบน**

| ข้อความ | ความหมาย | ต้องทำอะไร |
| --- | --- | --- |
| **ซิงก์แล้ว** (เขียว) | ข้อมูลในมือถือตรงกับชีต | ไม่ต้องทำอะไร |
| **กำลังซิงก์…** | กำลังส่ง/ดึงข้อมูล | รอสักครู่ |
| **รอส่ง 2** (เหลือง) | มี 2 รายการที่บันทึกไว้ในมือถือแต่ยังไม่ถึงชีต (เช่น เน็ตหลุด) | เมื่อมีเน็ต กดปุ่มนี้ → **ส่งรายการค้างและดึงข้อมูลล่าสุด** |

### 2.3 บันทึกรับเข้า (ของเข้าคลัง)

1. กด **บันทึก** → เลือกแท็บ **รับ-เบิก**
2. **อุปกรณ์ / วัสดุ**: กดช่องเลือก แล้วเลือกรายการ
   - รายการเยอะ ให้พิมพ์บางส่วนของชื่อหรือรหัสในช่องค้นหาด้านบนก่อน เช่น `quant` หรือ `EQ-017` ถ้าเหลือรายการเดียวจะเลือกให้อัตโนมัติ
   - เลือกแล้วจะเห็นกล่องบอกคงเหลือปัจจุบัน จุดเตือน และป้ายเตือนถ้ามี
3. กด **+ รับเข้า** (ปุ่มเปลี่ยนเป็นสีเขียว)
4. **จำนวน**: กด `+1` `+5` `+10` หรือพิมพ์ตัวเลข ปุ่ม `−` ลดทีละ 1 ปุ่ม **ล้าง** กลับเป็น 1
5. **วันที่ทำรายการ**: เป็นวันนี้อัตโนมัติ เปลี่ยนได้ถ้าบันทึกย้อนหลัง (ใส่วันในอนาคตไม่ได้)
6. **ผู้เบิก / ผู้บันทึก**: ชื่อผู้รับของ (พิมพ์ครั้งแรกแล้ว ครั้งต่อไปมีให้เลือก)
7. **หมายเหตุ**: เช่น `Lot 2509871` หรือเลขใบส่งของ
8. กด **บันทึกรายการ** → ขึ้นข้อความ "รับเข้า … (บันทึกลง Google Sheets แล้ว)"

> รับล็อตใหม่ที่วันหมดอายุต่างจากเดิม: ไปที่ **ทะเบียน** → **แก้ไข** รายการนั้น → เปลี่ยน **วันหมดอายุ** ให้เป็นวันของล็อตที่จะหมดก่อน

### 2.4 บันทึกเบิกออก (เอาของไปใช้)

ทำเหมือนข้อ 2.3 แต่กด **− เบิกออก** (ปุ่มเปลี่ยนเป็นสีแดง) และใส่ชื่อผู้เบิก

ถ้าเบิกมากกว่าที่มี จะขึ้น "เบิกเกินยอดคงเหลือ: มีอยู่ X …" และไม่บันทึก ให้ตรวจว่ามีของที่ยังไม่ได้บันทึกรับเข้าหรือไม่

### 2.5 บันทึกผิด แก้อย่างไร

รายการรับ-เบิกที่บันทึกแล้ว **แก้หรือลบไม่ได้** (เพื่อให้ตรวจสอบย้อนหลังได้) ให้บันทึกรายการกลับทิศเพื่อปรับยอด และเขียนหมายเหตุ

| บันทึกผิด | วิธีแก้ |
| --- | --- |
| เบิก 5 แต่จริง ๆ เบิก 3 | บันทึก **รับเข้า 2** หมายเหตุ `แก้ไขรายการเบิกเกิน วันที่ …` |
| รับเข้า 10 แต่จริง ๆ ได้ 8 | บันทึก **เบิกออก 2** หมายเหตุ `แก้ไขรายการรับเกิน วันที่ …` |
| เลือกผิดรายการ (เบิก A แต่จริง ๆ เบิก B) | บันทึก **รับเข้า** A กลับเท่าเดิม แล้วบันทึก **เบิกออก** B ใหม่ |

### 2.6 แจ้งซ่อม และติดตามสถานะ

**แจ้งซ่อม**
1. **บันทึก** → แท็บ **แจ้งซ่อม**
2. เลือกอุปกรณ์ วันที่แจ้ง ชื่อผู้แจ้ง และอธิบาย **อาการเสีย** ให้ละเอียด เช่น ข้อความ error ที่ขึ้นบนเครื่อง
3. เลือกสถานะ (ปกติคือ **รอดำเนินการ**) → **บันทึกใบแจ้งซ่อม**

**เปลี่ยนสถานะ** (เช่น ช่างมาซ่อมแล้ว)
1. ในแท็บ **แจ้งซ่อม** เลื่อนลงไปที่ **ใบแจ้งซ่อมทั้งหมด**
2. หาใบที่ต้องการ แล้วเปลี่ยนช่อง **สถานะ** เป็น **กำลังซ่อม** หรือ **ซ่อมเสร็จแล้ว** ระบบบันทึกทันที

> ซ่อมหรือทำ PM เสร็จแล้ว อย่าลืมไปที่ **ทะเบียน** → **แก้ไข** เครื่องนั้น → เลื่อน **วันครบกำหนดบำรุงรักษา** เป็นรอบถัดไป ไม่อย่างนั้นแอปจะยังเตือนอยู่

### 2.7 ดูภาพรวม

1. **เลือกช่วงวันที่**: วันนี้ / 7 วันล่าสุด / 30 วันล่าสุด / 3 เดือน / 6 เดือน / 1 ปี / ทั้งหมด / กำหนดเอง (กด **กำหนดเอง** แล้วเลือกวันเริ่มต้นและวันสิ้นสุด)
2. **เลือกรายการ**: ช่อง "ทุกรายการ" เลือกเป็นรายการเดียวได้ เพื่อดูตัวเลขของรายการนั้นในหน่วยของมัน
3. **ตัวเลขสรุป**

| การ์ด | คำนวณอย่างไร |
| --- | --- |
| ยอดยกมา | รับเข้ารวม − เบิกออกรวม ของทุกรายการ **ก่อน** วันเริ่มต้น |
| รับเข้าในช่วง | รับเข้ารวมระหว่างวันเริ่มต้นถึงวันสิ้นสุด |
| เบิกออกในช่วง | เบิกออกรวมระหว่างวันเริ่มต้นถึงวันสิ้นสุด |
| คงเหลือปัจจุบัน | ยอดยกมา + รับเข้า − เบิกออก (ยอด ณ วันสิ้นสุด) |
| แจ้งเตือนเร่งด่วน | จำนวนรายการที่หมดอายุแล้วหรือจะหมดอายุภายใน 30 วัน และเครื่องที่ถึงกำหนดบำรุงรักษาภายใน 30 วันหรือเลยกำหนด กดการ์ดเพื่อดูรายการ |

> เมื่อเลือก "ทุกรายการ" ตัวเลขจะนับรวมทุกหน่วย (ชุด + ขวด + แพ็ก …) ใช้ดูแนวโน้มเท่านั้น ถ้าต้องการยอดจริง ให้เลือกทีละรายการ หรือดูในเมนู **คงคลัง**

4. **ต้องดำเนินการ**: รายการที่ใกล้/หมดอายุ และเครื่องที่ถึงกำหนดบำรุง เรียงจากเร่งด่วนที่สุด แถวสุดท้ายบอกจำนวนรายการที่คงเหลือต่ำกว่าจุดเตือน กด **ดูรายการ** เพื่อดูทั้งหมด

### 2.8 คงคลัง และบัญชีคุมยอด

1. กด **คงคลัง** จะเห็นทุกรายการ พร้อมยอดยกมา รับเข้า เบิกออก คงเหลือ (ตามช่วงวันที่ที่เลือกในหน้าภาพรวม)
2. ค้นหาด้วยชื่อหรือรหัส หรือกดตัวกรอง: ต้องดำเนินการ / ใกล้หมดอายุ / ถึงกำหนดบำรุง / ต่ำกว่าจุดเตือน / สิ้นเปลือง / ทรัพย์สินถาวร
3. สีของป้าย: **แดง** = หมดอายุแล้วหรือเหลือไม่เกิน 30 วัน, **เหลือง** = เหลือไม่เกิน 90 วัน หรือใกล้ถึงกำหนดบำรุง
4. **กดที่รายการ** เพื่อเปิด **บัญชีคุมยอด**: เห็นยอดยกมา แต่ละรายการรับ-เบิก (วันเวลา ผู้บันทึก หมายเหตุ) ยอดคงเหลือหลังแต่ละรายการ และประวัติแจ้งซ่อม
5. ในหน้าบัญชีคุมยอดมีปุ่ม **+ รับเข้า** **− เบิกออก** (เปิดฟอร์มพร้อมเลือกรายการไว้ให้) และ **แก้ไขทะเบียน**

### 2.9 ทะเบียนอุปกรณ์

**เพิ่มรายการใหม่**
1. **ทะเบียน** → กรอกชื่อ เลือกประเภท หน่วยนับ จุดเตือน วันหมดอายุ วันบำรุงรักษา (สองช่องหลังเว้นว่างได้)
2. กด **เพิ่มเข้าทะเบียน** ระบบออกรหัส EQ ให้อัตโนมัติ
3. ถ้าชื่อซ้ำกับที่มีอยู่ ระบบจะไม่ให้เพิ่ม

**แก้ไข**: กด **แก้ไข** ท้ายรายการ แก้แล้วกด **บันทึกการแก้ไข** (กด **ยกเลิกแก้ไข** ถ้าไม่ต้องการ)

### 2.10 ส่งออก Excel

1. หน้า **ภาพรวม** เลือกช่วงวันที่ (และรายการ ถ้าต้องการ)
2. กด **ส่งออก Excel** ได้ไฟล์ `รายงานคงคลัง_วันเริ่ม_ถึง_วันสิ้นสุด.xlsx` มี 4 แท็บ: สรุปคงคลัง, รายการรับ-เบิก, แจ้งซ่อม, ทะเบียนอุปกรณ์

> มือถือบางรุ่นดาวน์โหลดไฟล์จากแอปที่ทำงานบน Google Apps Script ไม่ได้ ถ้ากดแล้วไม่มีไฟล์ ให้ส่งออกจากคอมพิวเตอร์ หรือเปิด Google ชีต → **ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)** (ได้ข้อมูลดิบทั้งหมด)

### 2.11 ตอนไม่มีอินเทอร์เน็ต

- บันทึกได้ตามปกติ รายการจะเก็บไว้ในมือถือ และขึ้นข้อความ "บันทึกไว้ในเครื่องแล้ว แต่ยังไม่ได้ส่งเข้าชีต"
- ปุ่มมุมขวาบนจะเป็น **รอส่ง (จำนวน)**
- เมื่อมีเน็ต กดปุ่มนั้น → **ส่งรายการค้างและดึงข้อมูลล่าสุด**
- **อย่าล้างประวัติ/ข้อมูลเว็บไซต์ของเบราว์เซอร์** ก่อนส่ง ไม่อย่างนั้นรายการที่ค้างจะหาย
- ระหว่างออฟไลน์ ยอดในมือถือเครื่องนี้อาจยังไม่รวมรายการที่คนอื่นบันทึก

### 2.12 โหมดสว่าง / มืด

**ตั้งค่า** → **การแสดงผล** → เลือก **ตามเครื่อง** / **สว่าง** / **มืด** (บนคอมพิวเตอร์มีปุ่มรูปพระจันทร์มุมขวาบน)

## ส่วนที่ 3 งานของผู้ดูแลระบบ

### 3.1 แก้ข้อมูลในชีตโดยตรงได้แค่ไหน

| แท็บ | แก้ในชีตได้ไหม |
| --- | --- |
| `Equipment_Master` | **ได้** เฉพาะ Material_Name, Category, Unit, Min_Stock_Alert, Expiration_Date, Next_Maintenance_Date (วันที่ใช้รูปแบบ `2027-03-31`) **ห้ามแก้ Equipment_ID** ของรายการที่มีการรับ-เบิกแล้ว และห้ามลบแถวนั้น |
| `Transactions` | **ห้ามแก้ ห้ามลบ ห้ามแทรกแถว** ถ้าผิดให้บันทึกกลับทิศในแอป (ข้อ 2.5) |
| `Maintenance_Log` | เปลี่ยนสถานะผ่านแอปจะดีที่สุด แก้ช่อง Status ในชีตได้ ถ้าใช้ค่า `รอดำเนินการ` `กำลังซ่อม` หรือ `ซ่อมเสร็จแล้ว` เท่านั้น |

ถ้ามีคนลบแถวใน `Transactions` แอปจะดาวน์โหลดข้อมูลใหม่ทั้งหมดอัตโนมัติ แต่ยอดที่หายไปจะกู้คืนไม่ได้ นอกจากใช้ประวัติเวอร์ชัน (ข้อ 3.2)

### 3.2 สำรองข้อมูล

- **ทุกเดือน**: เปิด Google ชีต → **ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)** เก็บไว้ในเครื่องหรือไดรฟ์ของหน่วยงาน
- **กู้คืน**: Google ชีต → **ไฟล์ → ประวัติเวอร์ชัน → ดูประวัติเวอร์ชัน** เลือกเวอร์ชันก่อนเกิดปัญหา → **คืนค่าเวอร์ชันนี้**
- จำกัดคนที่แก้ไขชีตได้: ปุ่ม **แชร์** ของ Google ชีต ให้สิทธิ์ "ผู้แก้ไข" เฉพาะผู้ดูแล เจ้าหน้าที่ทั่วไปไม่ต้องมีสิทธิ์ในชีต เพราะใช้งานผ่านแอป

### 3.3 อัปเดตโปรแกรม (เมื่อได้ Code.gs หรือ index.html เวอร์ชันใหม่)

1. เปิด Apps Script (ข้อ 1.4) แทนที่เนื้อหาไฟล์ที่เปลี่ยนแบบข้อ 1.5 / 1.6 แล้วบันทึก
2. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ (Manage deployments)**
3. เลือกรายการ `ใช้งานจริง` → กดไอคอนดินสอ ✎ **แก้ไข**
4. ช่อง **เวอร์ชัน (Version)** เลือก **เวอร์ชันใหม่ (New version)** → **ทำให้ใช้งานได้**

ลิงก์เดิมใช้ต่อได้ ไม่ต้องส่งลิงก์ใหม่ให้เจ้าหน้าที่ (ห้ามกด "การทำให้ใช้งานได้รายการใหม่" เพราะจะได้ลิงก์ใหม่)

ถ้าแก้แล้วมือถือยังเห็นแบบเก่า: ปิดแอปแล้วเปิดใหม่ หรือดึงหน้าจอลงเพื่อโหลดใหม่

### 3.4 เปลี่ยนลิงก์ (เช่น ลิงก์หลุดไปนอกกลุ่มงาน)

1. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** ตั้งค่าแบบข้อ 1.8 ได้ลิงก์ใหม่
2. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้** เลือกรายการเก่า → **เก็บถาวร (Archive)** ลิงก์เก่าจะใช้ไม่ได้ทันที
3. ส่งลิงก์ใหม่ให้เจ้าหน้าที่ แต่ละคนต้องเพิ่มไอคอนที่หน้าจอโฮมใหม่ (ข้อ 2.1) และควร **ส่งรายการค้างก่อน** ถ้ามี

### 3.5 ความปลอดภัยและขีดจำกัด

- ใครมีลิงก์ใช้งานได้ทันทีโดยไม่ต้องลงชื่อ ส่งลิงก์เฉพาะในกลุ่มงาน ระบบนี้ออกแบบสำหรับข้อมูลพัสดุ **ไม่ควรบันทึกข้อมูลคดีหรือข้อมูลบุคคล** ในช่องหมายเหตุ
- ระบบบันทึกชื่อผู้เบิกตามที่พิมพ์ ไม่ได้ยืนยันตัวตน
- Google ชีตเก็บได้สูงสุด 10 ล้านเซลล์ แท็บ Transactions ใช้ 7 คอลัมน์ = ประมาณ 1.4 ล้านรายการ ถ้าบันทึกวันละ 100 รายการ ใช้ได้ประมาณ 38 ปี
- `API_KEY` ใน `Code.gs` ใช้เฉพาะกรณีนำ `index.html` ไปฝากบนเว็บอื่น (ดู README.md) ถ้าใช้ลิงก์ Web App ตามคู่มือนี้ ไม่ต้องตั้ง

| เปิดลิงก์แล้วขอให้ลงชื่อเข้า Google หรือขึ้น *"คุณต้องได้รับสิทธิ์"* | ตั้ง **ผู้ที่มีสิทธิ์เข้าถึง** ไม่ใช่ "ทุกคน" | จัดการการทำให้ใช้งานได้ → แก้ไข → ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** → เวอร์ชันใหม่ |
| ปุ่มมุมขวาบนขึ้น **รอส่ง** ค้าง | เน็ตหลุด หรือเซิร์ฟเวอร์ปฏิเสธรายการ | กดปุ่ม → ส่งรายการค้าง ถ้าขึ้นข้อความ error ให้อ่านสาเหตุ เช่น "ยอดคงเหลือไม่พอ" แปลว่ามีคนอื่นเบิกไปก่อน |
| ซิงก์แล้วขึ้น *"ยอดคงเหลือไม่พอ"* | ระหว่างออฟไลน์ มีคนอื่นเบิกรายการเดียวกันไปจนไม่พอ | ตรวจนับของจริง แล้วบันทึกรับเข้าส่วนที่ขาดพร้อมหมายเหตุ รายการที่ค้างจะส่งได้ |
| มือถือสองเครื่องเห็นยอดไม่เท่ากัน | เครื่องหนึ่งยังไม่ได้ดึงข้อมูลล่าสุด | **ตั้งค่า** → **ดึงข้อมูลล่าสุดจาก Google Sheets** หรือปิดแล้วเปิดแอปใหม่ |
| แก้โค้ดแล้วยังเห็นแบบเดิม | ยังไม่ได้ทำ "เวอร์ชันใหม่" | ทำตามข้อ 3.3 |
| แอปเตือนตลอดว่าเครื่องถึงกำหนดบำรุง ทั้งที่ทำแล้ว | ยังไม่ได้เลื่อนวันบำรุงรักษาในทะเบียน | **ทะเบียน → แก้ไข** เปลี่ยนวันครบกำหนดบำรุงรักษา |
| ตอนรัน `setup` ขึ้น *"หัวตารางของชีต … ไม่ตรง"* | แถวที่ 1 ถูกแก้หรือชื่อแท็บผิด | แก้หัวตารางให้ตรงตามข้อความ แล้วรัน `setup` ใหม่ |
| ขึ้น *"เบราว์เซอร์นี้เก็บข้อมูลในเครื่องไม่ได้"* | เปิดในโหมดไม่ระบุตัวตน หรือเบราว์เซอร์ปิดการเก็บข้อมูล | เปิดในเบราว์เซอร์ปกติ (รายการที่บันทึกตอนมีเน็ตถึงชีตแล้ว ไม่หาย) |
| กดส่งออก Excel แล้วไม่มีไฟล์ | มือถือบางรุ่นบล็อกการดาวน์โหลดจากแอป Apps Script | ส่งออกจากคอมพิวเตอร์ หรือดาวน์โหลดจาก Google ชีต (ข้อ 2.10) |
