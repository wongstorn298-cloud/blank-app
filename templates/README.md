# แม่แบบ Google Sheet (ไฟล์เปล่า พร้อมนำเข้า)

โฟลเดอร์นี้มีแม่แบบ 3 ไฟล์ ใช้สร้าง Google Sheet ของจริงที่ Dashboard และ LINE bot อ่านได้ทันที
**ทุกไฟล์ไม่มีข้อมูล** มีแค่ชื่อแท็บ หัวคอลัมน์ รูปแบบเซลล์ ตัวเลือก (dropdown) และสูตร

| ไฟล์ | ใช้ทำชีตอะไร | แท็บ |
|---|---|---|
| `แม่แบบ-ชีตคดี.xlsx` | คดีส่งตรวจ DNA (1 แถว = 1 คดี) | `คำอธิบาย`, `ข้อมูลคดี` |
| `แม่แบบ-ชีตงานตรวจ.xlsx` | งานตรวจรายเดือน งบประมาณ และ Lot | `คำอธิบาย`, `ข้อมูลเคส`, `ข้อมูลงบ`, `ข้อมูล Lot`, `หมายเหตุ` |
| `แม่แบบ-ชีต-Lot-พัสดุ.xlsx` | Lot พัสดุ แยกเป็นชีตของตัวเอง (ใช้ภายหลัง) | `คำอธิบาย`, `ข้อมูล Lot`, `หมายเหตุ` (ไม่บังคับ) |

แท็บ `คำอธิบาย` อธิบายทุกคอลัมน์เป็นภาษาไทย ระบบไม่อ่านแท็บนี้ จะเก็บไว้หรือลบทิ้งก็ได้

> แม่แบบ Lot พัสดุแยกไฟล์: Dashboard บน Apps Script รองรับชีตที่มีแค่แท็บ `ข้อมูล Lot` แล้ว เพิ่มเป็นแหล่งข้อมูลได้เลย Dashboard จะแสดงเฉพาะเมนู Lot

## 1. นำแม่แบบเข้า Google Sheets

วิธีที่ 1: อัปโหลดแล้วเปิด
1. เข้า Google Drive แล้วกด **ใหม่ (New) → อัปโหลดไฟล์ (File upload)** เลือกไฟล์แม่แบบ
2. ดับเบิลคลิกไฟล์ที่อัปโหลด แล้วเลือก **เปิดด้วย Google ชีต (Open with Google Sheets)**
3. กด **ไฟล์ → บันทึกเป็น Google ชีต (File → Save as Google Sheets)** ระบบอ่านได้เฉพาะไฟล์ Google ชีต ไม่อ่านไฟล์ .xlsx ใน Drive
4. ลบไฟล์ .xlsx ที่อัปโหลดไว้ออกจาก Drive ได้

วิธีที่ 2: นำเข้าในชีตเปล่า
1. สร้าง Google ชีตใหม่ แล้วกด **ไฟล์ → นำเข้า (File → Import) → อัปโหลด**
2. เลือก **แทนที่สเปรดชีต (Replace spreadsheet)**

หลังนำเข้า ให้ตรวจ 1 ครั้งใน Google Sheets ว่าทุกอย่างทำงาน
- [ ] dropdown ในคอลัมน์ `สถานะ` และ `ประเภทคดี (เลือก)` ขึ้นตัวเลือกครบ
- [ ] กรอกข้อมูลทดลอง 1 แถว (ใช้ค่าสมมติ) แล้วคอลัมน์สูตรคำนวณถูก: `ข้อสังเกต (ผิดปกติ)` (ชีตคดี), `เดือน` และ `ปีปฏิทิน (พ.ศ.)` (ข้อมูลเคส), `รอบพัสดุ (26–25) สิ้นสุดเดือน`, `ปีงบ (ตามรอบ)`, `วันที่ประมาณการ (1=ใช่)` (ข้อมูล Lot)
- [ ] เซลล์วันที่แสดงเป็นวันที่ และเลข บก. ที่พิมพ์ไม่กลายเป็นวันที่
- [ ] ลบแถวทดลองออก

(สูตรทดสอบแล้วกับ LibreOffice และใช้ฟังก์ชันพื้นฐานที่มีใน Google Sheets แต่ยังไม่ได้ทดสอบใน Google Sheets จริง จึงต้องตรวจตามรายการนี้ 1 ครั้ง)

## 2. ห้ามเปลี่ยนชื่อแท็บและหัวคอลัมน์

Dashboard และ LINE bot หาข้อมูลจาก**ชื่อแท็บ**และ**ชื่อหัวคอลัมน์** ถ้าเปลี่ยนชื่อ ระบบจะหาไม่เจอหรือนับผิด
- ระบบดูว่าเป็นชีตแบบไหนจากชื่อแท็บและหัวคอลัมน์แรก: `ข้อมูลคดี` ต้องขึ้นต้นด้วยคอลัมน์ `เลข บก.`, `ข้อมูลเคส` และ `ข้อมูลงบ` ขึ้นต้นด้วย `ปีงบประมาณ (พ.ศ.)`, `ข้อมูล Lot` ขึ้นต้นด้วย `ลำดับ`
- แท็บ `ข้อมูลเคส` และ `ข้อมูลงบ` อ่านตาม**ลำดับคอลัมน์** ห้ามสลับ แทรก หรือลบคอลัมน์
- หัวคอลัมน์ต้องอยู่แถวที่ 1 ห้ามแทรกแถวชื่อเรื่องไว้ด้านบน
- เพิ่มคอลัมน์ของตัวเองได้ที่**ท้ายตาราง**ของแท็บ `ข้อมูลคดี` และ `ข้อมูล Lot` แต่ห้ามใส่ DNA profile หรือข้อมูลบุคคล (เลขบัตร เบอร์โทร)
- เพิ่มแท็บอื่น เช่น แท็บสรุปของตัวเอง ได้ ระบบไม่อ่าน

คอลัมน์สีเทาเป็น**สูตร** ห้ามพิมพ์ทับ แม่แบบเตรียมสูตรไว้ (ชีตคดี 3,000 แถว, ข้อมูลเคส 600 แถว, ข้อมูล Lot 2,000 แถว) ถ้าข้อมูลเกิน ให้คลิกเซลล์สูตรแถวสุดท้ายแล้วลากจุดมุมขวาล่างลงไป

ช่องสีเหลืองในแท็บ `ข้อมูลคดี` แถวที่ 2 คือ**เกณฑ์ของกลางผิดปกติ (ชิ้น)** ใส่ไว้ 50 (ค่าเดียวกับที่ Dashboard ใช้เมื่อไม่มีเกณฑ์) แก้เป็นค่าที่หน่วยงานใช้ได้

### dropdown ที่แก้รายการได้

| แท็บ | คอลัมน์ | ตัวเลือก |
|---|---|---|
| ข้อมูลคดี | สถานะ | กำลังดำเนินการ / เสร็จแล้ว รอรับผล / รับผลไปแล้ว (**ห้ามเปลี่ยนคำ** ระบบนับสถานะจากคำเหล่านี้ ช่องว่างหรือคำอื่นนับเป็น กำลังดำเนินการ) |
| ข้อมูลคดี | ประเภทคดี (เลือก) | ทรัพย์, เพศ, ชีวิตและร่างกาย, พรบ.อาวุธปืน, ยาเสพติด, อื่น ๆ — **แก้ เพิ่ม หรือลบรายการได้** |
| ข้อมูลงบ | หมวด | งบดำเนินงาน, วัสดุวิทย์ฯ, เหลือจ่าย, ซ่อมบำรุง, สอบเทียบ, อื่นๆ/เหตุพิเศษ, ขยะติดเชื้อ (กราฟงบประมาณใน Dashboard แสดงเฉพาะหมวดเหล่านี้) |
| ข้อมูล Lot | ที่มาของวันที่ | ระบุในต้นฉบับ / ประมาณการจากลำดับ Lot ก่อน-หลัง |

วิธีแก้รายการ: เลือกทั้งคอลัมน์ → **ข้อมูล → การตรวจสอบข้อมูล (Data → Data validation)** → คลิกกฎของคอลัมน์นั้น → แก้รายการ → เสร็จสิ้น
ถ้าพิมพ์ค่าที่ไม่อยู่ในรายการ ชีตจะขึ้นเครื่องหมายเตือนแต่ยังบันทึกได้ ประเภทคดีใหม่จะแสดงใน Dashboard เป็นประเภทแยกต่างหาก

คอลัมน์ `ผู้ตรวจ (เลือก)` ไม่มี dropdown ในแม่แบบ (ไม่ใส่ชื่อคนไว้ในไฟล์ของ repo) เพิ่มเองได้ด้วยวิธีเดียวกัน เลือก **เมนูแบบเลื่อนลง (Dropdown)** แล้วพิมพ์ชื่อเจ้าหน้าที่ หรือดึงจากช่วงเซลล์ในแท็บของตัวเอง ชื่อต้องสะกดเหมือนกันทุกแถว ไม่อย่างนั้นสรุปรายเจ้าหน้าที่จะแยกเป็นคนละคน

## 3. ย้ายข้อมูลเดิมเข้าแม่แบบ

1. เปิดไฟล์เดิมกับ Google ชีตที่สร้างจากแม่แบบไว้คู่กัน
2. เลือกช่วงข้อมูลในไฟล์เดิม (ไม่รวมแถวหัวคอลัมน์) แล้วคัดลอก
3. คลิกเซลล์แถวที่ 2 ของคอลัมน์ที่ตรงกันในแม่แบบ แล้ววางแบบ**ค่าเท่านั้น**: คลิกขวา → **วางแบบพิเศษ → วางเฉพาะค่า (Paste special → Values only)** หรือกด `Ctrl+Shift+V` เพื่อไม่ให้รูปแบบและสูตรเดิมทับแม่แบบ
4. วางเป็นช่วงตามคอลัมน์ ห้ามวางทับคอลัมน์สีเทา (สูตร)

| แท็บ | คอลัมน์ที่วางจากไฟล์เดิม |
|---|---|
| ข้อมูลคดี | `เลข บก.` ถึง `ของกลาง (ชิ้น)` (A–M ตรงกับไฟล์เดิม) แล้ววาง `นับในสถิติ` ลงคอลัมน์ N แยกอีกครั้ง |
| ข้อมูลเคส | A–B (ปีงบ, ลำดับเดือน) และ E–G (ของกลาง, ตัวอย่าง, หมายเหตุ) |
| ข้อมูลงบ | A–E ทั้งหมด |
| ข้อมูล Lot | A–H (ลำดับ ถึง ที่มาของวันที่) |
| หมายเหตุ | A–B |

แม่แบบชีตคดีไม่มีคอลัมน์ `เดือนที่รับ`, `ปี พ.ศ. (รับ)`, `ปีเลขรายงาน`, `ลำดับเลขรายงาน`, `อันดับ (ช่วยคำนวณ)` และไม่มีคอลัมน์ `User ID (LINE)` ไม่ต้องย้ายมา เพราะ Dashboard และ LINE bot คำนวณเดือน/ปีจากวันที่รับเอง

หลังวาง ให้ตรวจ
- วันที่ต้องเป็น**วันที่จริง** (คลิกเซลล์แล้วเห็นเป็นวันที่ ไม่ใช่ข้อความชิดซ้าย) วันที่ที่เป็นข้อความระบบจะไม่นับ และคอลัมน์ ข้อสังเกต จะขึ้น "ไม่มีวันที่รับหรือไม่ใช่วันที่"
- `นับในสถิติ` ต้องเป็นตัวเลข 0 (ไม่นับ) หรือว่าง/1 (นับ)
- ดูคอลัมน์ `ข้อสังเกต (ผิดปกติ)` แล้วแก้แถวที่มีข้อความเตือน

ชีตคดีที่ยังไม่มีแถวข้อมูลเลย Dashboard จะแจ้งว่า "ไม่มีแถวที่มีวันที่รับ" เป็นเรื่องปกติ ให้ใส่ข้อมูลก่อนแล้วค่อยเชื่อม

## 4. การแชร์

- ตั้ง **การเข้าถึงทั่วไป (General access) = จำกัด (Restricted)** ห้ามตั้ง "ทุกคนที่มีลิงก์"
- เพิ่มอีเมลเฉพาะคนที่ใช้ Dashboard เป็น **ผู้มีสิทธิ์อ่าน (Viewer)** คนที่กรอกข้อมูลเท่านั้นที่ได้ **ผู้แก้ไข (Editor)**
- เมื่อมีคนย้ายงานหรือออก ให้ลบสิทธิ์ใน Sheet ทันที
- Dashboard ที่เปิดผ่าน Apps Script อ่านชีตด้วยสิทธิ์ของผู้ใช้แต่ละคน จึงใช้กับชีตแบบจำกัดได้ ส่วนไฟล์ `dashboard/index.html` ที่เปิดตรงจากเครื่อง (ดึงผ่านลิงก์) ต้องตั้งแชร์แบบทุกคนที่มีลิงก์ **ห้ามใช้วิธีนั้นกับชีตข้อมูลจริง**

## 5. ข้อมูลจริงห้ามเข้า repo

- ไฟล์ในโฟลเดอร์นี้ต้อง**เปล่า**เสมอ ห้ามกรอกข้อมูลจริงลงไฟล์ในโฟลเดอร์นี้ แล้ว commit
- ห้ามดาวน์โหลด Google ชีตจริงเป็น .xlsx/.csv มาไว้ใน repo และห้ามถ่ายภาพหน้าจอข้อมูลจริงใส่เล่ม
- ถ้าจะแก้แม่แบบ ให้แก้ที่สคริปต์ `tools/make_templates.py` แล้วรัน `python3 tools/make_templates.py` เพื่อสร้างไฟล์ใหม่ (ไม่แก้ไฟล์ .xlsx ด้วยมือ)
