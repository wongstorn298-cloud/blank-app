# โครงสร้างข้อมูล (เฉพาะชื่อคอลัมน์ ไม่มีค่าข้อมูลจริง)

ได้จากการอ่านไฟล์ Excel ที่ฝังอยู่ใน Dashboard ต้นฉบับ ใช้เป็นแบบในการสร้างข้อมูลจำลองและเขียนโค้ด

## ไฟล์ `cases` (ข้อมูลคดี)

แท็บข้อมูลหลัก **ข้อมูลคดี** (~700 แถว) คอลัมน์ตามลำดับ:

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| เลข บก. | ข้อความ | รูปแบบ `ลำดับ/ปีพ.ศ.` เช่น `123/2568` ใช้เป็นเลขคดีที่บอตค้นหา |
| เลขรายงาน | ข้อความ | รูปแบบ `NN-YY-NNNNN` |
| สภ. (ท้องที่) | ข้อความ | |
| จังหวัด | ข้อความ | |
| เลขหนังสือนำส่ง | ข้อความ | |
| ลงวันที่ | วันที่ | |
| วันที่รับ | วันที่ | ใช้กำหนดเดือน/ปีของคดีในสรุป |
| วันที่ตรวจเสร็จ | วันที่ | |
| วันที่มารับผล | วันที่ | |
| สถานะ | ข้อความ | `กำลังดำเนินการ`, `เสร็จแล้ว รอรับผล`, `รับผลไปแล้ว` — ระบบนับค่าอื่นหรือช่องว่างเป็น "กำลังดำเนินการ" (ดูด้านล่าง) |
| ประเภทคดี (เลือก) | ข้อความ (dropdown) | ตัวอย่างค่า: `ทรัพย์`, `พรบ.อาวุธปืน`, `เพศ` |
| ผู้ตรวจ (เลือก) | ข้อความ (dropdown) | ชื่อเจ้าหน้าที่ — ข้อมูลส่วนบุคคล |
| ของกลาง (ชิ้น) | ตัวเลข | |
| เดือนที่รับ | วันที่ | คำนวณ |
| ปี พ.ศ. (รับ) | ตัวเลข | คำนวณ |
| นับในสถิติ | ตัวเลข 0/1 | คำนวณ |
| ข้อสังเกต (ผิดปกติ) | ข้อความ | คำนวณ |
| ปีเลขรายงาน, ลำดับเลขรายงาน | ตัวเลข | คำนวณ |
| อันดับ (ช่วยคำนวณ), ตั้งค่า, เกณฑ์ของกลางผิดปกติ (ชิ้น) > | | ช่วยคำนวณ/ตั้งค่า |

แท็บสรุปอื่น: `Dashboard`, `สภ.และประเภทคดี`, `ผู้ตรวจ`

> **คอลัมน์ `User ID (LINE)` ถูกลบแล้ว** (เจ้าของตัดสินใจ 3 พ.ย. 2569) ระบบไม่อ่านและไม่ต้องใช้คอลัมน์นี้ ข้อมูลจำลองไม่มีคอลัมน์นี้ ถ้าชีตจริงยังมีอยู่ระหว่างรอลบ Dashboard / LINE bot ก็ไม่อ่านและไม่ส่งออก (อ่านเฉพาะคอลัมน์ที่ระบุใน `apps-script/Code.gs` และ `Stats.gs`)

**การนับสถานะ** (กติกาเดียวกันทั้ง Dashboard `statusOf` ใน `dashboard/index.html` และ `Stats.statusGroup` ใน `apps-script/Stats.gs` ที่ LINE bot ใช้)

| ค่าในช่อง สถานะ | นับเป็น |
|---|---|
| `รับผลไปแล้ว` | เสร็จสิ้น (ไม่ค้าง) |
| มีคำว่า `รอรับผล` เช่น `เสร็จแล้ว รอรับผล` | เสร็จแล้ว รอรับผล (ค้าง) |
| `กำลังดำเนินการ`, ช่องว่าง หรือค่าอื่น | กำลังดำเนินการ (ค้าง) — LINE bot บอกจำนวนแถวที่สถานะว่างไว้ด้วย ให้ผู้ดูแลกรอกเพิ่ม |

นับเฉพาะแถวที่มีวันที่รับ และ `นับในสถิติ` ไม่เป็น 0

> ⚠️ **คุณภาพข้อมูล (ณ วันที่ได้รับไฟล์):** คอลัมน์ `ประเภทคดี (เลือก)` และ `ผู้ตรวจ (เลือก)` มีค่าเพียง 7 จาก ~700 แถว สรุปรายเจ้าหน้าที่/รายประเภทจะว่างเกือบทั้งหมดจนกว่าจะกรอกข้อมูลเพิ่ม ระบบต้องแสดง "ไม่ระบุ" อย่างเหมาะสม

## ไฟล์ `lab` (ข้อมูลห้องปฏิบัติการ)

- **ข้อมูลเคส**: ปีงบประมาณ (พ.ศ.), ลำดับเดือนในปีงบ, เดือน, ปีปฏิทิน (พ.ศ.), จำนวนของกลาง (ชิ้น), จำนวนตัวอย่างตรวจ, หมายเหตุ
- **ข้อมูลงบ**: ปีงบประมาณ (พ.ศ.), รายการ (ตามต้นฉบับ), หมวด, จำนวนเงิน (บาท), หมายเหตุ
- **ข้อมูล Lot**: ลำดับ, ชีตต้นฉบับ, แถวต้นฉบับ, วันที่ในต้นฉบับ, วันที่ใช้คำนวณ (แก้ไขได้), Lot No., จำนวนตัวอย่าง, ที่มาของวันที่, รอบพัสดุ (26–25) สิ้นสุดเดือน, ปีงบ (ตามรอบ), วันที่ประมาณการ (1=ใช่)
- แท็บสรุป: `Dashboard`, `สรุปรายเดือน`, `สรุปรายปี`, `งบประมาณ`, `Lot 26-25`, `หมายเหตุ`

## ชนิดแหล่งข้อมูล (ระบบตรวจจากชื่อแท็บและหัวคอลัมน์แถวที่ 1)

ผู้ดูแลเพิ่ม Google Sheet ด้วยลิงก์ในหน้า "แหล่งข้อมูล" ของ Dashboard ระบบตรวจ (`inspectSheet_` ใน `apps-script/Admin.gs`) แล้วจัดเป็น 1 ใน 3 แบบ แท็บอื่นในไฟล์ (เช่น `คำอธิบาย` ของแม่แบบ หรือแท็บสรุป) ไม่อ่าน · ผลตรวจมีแค่ชื่อแท็บ จำนวนแถว (นับแถวที่คอลัมน์ A มีค่า) และหัวคอลัมน์ที่ขาด ไม่มีค่าในเซลล์

| แบบ | เงื่อนไข | หัวคอลัมน์ที่ต้องมี | ผล |
|---|---|---|---|
| ชีตคดี | มีแท็บ `ข้อมูลคดี` | `เลข บก.` เป็นคอลัมน์ A + `สภ.` `จังหวัด` `วันที่รับ` `สถานะ` `ของกลาง` (ขึ้นต้นด้วย ตำแหน่งใดก็ได้) · ควรมี `เลขรายงาน` `วันที่ตรวจเสร็จ` `วันที่มารับผล` `ประเภทคดี` `ผู้ตรวจ` `นับในสถิติ` | ขาดคอลัมน์ที่ต้องมี = ไม่รับ · ตั้งเป็น "ชีตหลัก" ได้ |
| ชีตงานตรวจ | ไม่มี `ข้อมูลคดี` และมีอย่างน้อย 1 แท็บที่ถูกต้องจาก `ข้อมูลเคส` / `ข้อมูลงบ` / `ข้อมูล Lot` | `ข้อมูลเคส`: A ปีงบประมาณ, B ลำดับเดือนในปีงบ, E จำนวนของกลาง, F จำนวนตัวอย่างตรวจ · `ข้อมูลงบ`: A ปีงบประมาณ, B รายการ, C หมวด, D จำนวนเงิน · `ข้อมูล Lot`: A ลำดับ + `วันที่ใช้คำนวณ` `Lot No` `จำนวนตัวอย่าง` | แสดงเฉพาะเมนูของแท็บที่ถูกต้อง (ภาพรวม / งบประมาณ / Lot พัสดุ) พร้อมข้อความแจ้งแท็บที่ไม่มี |
| ชีต Lot พัสดุ | ชีตงานตรวจที่มีแค่ `ข้อมูล Lot` (และ `หมายเหตุ` ถ้ามี) | ตาม `ข้อมูล Lot` ข้างบน | ป้าย "Lot พัสดุ" เมนู Lot พัสดุอย่างเดียว |

ไม่ตรงแบบใดเลย = ไม่รับ พร้อมรายชื่อแท็บที่พบ · คอลัมน์คำนวณที่แม่แบบใน `templates/` ตัดออก (`เดือนที่รับ`, `ปี พ.ศ. (รับ)`, `ปีเลขรายงาน`, `ลำดับเลขรายงาน`, `อันดับ (ช่วยคำนวณ)`) ระบบไม่ใช้ · เกณฑ์ของกลางผิดปกติอ่านจากคอลัมน์ `เกณฑ์ของกลางผิดปกติ (ชิ้น) >` (แม่แบบใส่ 50, ไม่มี = 50)

## รายชื่อผู้ใช้

**ไม่ใช้แท็บ `ผู้ใช้` แล้ว** รายชื่อผู้ใช้/ผู้ดูแลจัดการในหน้า "ผู้ใช้" ของ Dashboard และเก็บใน Script Properties (อีเมล, ชื่อ, หมายเหตุ, เป็นผู้ดูแลหรือไม่) · แท็บ `ผู้ใช้` (อีเมล, ชื่อ, หมายเหตุ) ในชีตคดีของระบบเดิมถูกอ่าน**ครั้งเดียว**ตอนย้ายระบบ (เจ้าของเปิด Dashboard ครั้งแรก) แล้วลบได้
